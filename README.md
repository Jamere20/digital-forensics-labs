# Digital Forensics Labs

This repository contains digital forensics and filesystem analysis labs completed using forensic tools such as WinHex, FTK Imager, and Autopsy.

## Topics Covered
- Corrupted file recovery
- XOR analysis
- NTFS data attributes
- MFT timestamp analysis
- Data runs and cluster analysis
- Hex-level investigation

## Tools Used
- WinHex
- FTK Imager
- Autopsy
- OSForensics
